Цель проекта: оценить динамику пользовательской базы, активность игроков, финансовые результаты и показатели вирусного роста.

Что делал(а):

— Изучил(а) исходные данные и провёл(а) анализ количества пользователей и игровых сессий.
— Рассчитал(а) долю проблемных сессий по типам устройств и оценил(а) возможные причины аномалий.
— Определил(а) коэффициент вирусности игры и средний размер будущих когорт пользователей.
— Проанализировал(а) динамику выручки и влияние маркетинговой кампании на финансовые показатели.
— Оценил(а) изменения ключевых метрик DAU / WAU / MAU и их соотношение.
— Рассчитал(а) долю лояльных пользователей, протестировав разные критерии определения лояльности.

Используемые нструменты: PostgreSQL (CASE WHEN, агрегации, JOIN-ы, CTE/подзапросы), Excel (постобработка, визуализация).

Результат: подготовлена презентация с основными выводами и визуализациями, демонстрирующая динамику пользовательской активности и влияние маркетинговых факторов на выручку игры.

Аналитические компетенции:
Исследование пользовательской активности и динамики ключевых метрик DAU / WAU / MAU.
Расчёт и интерпретация показателей вирусности и удержания пользователей.
Анализ выручки и оценка эффекта маркетинговых кампаний.
Определение и сравнение когорт пользователей по различным критериям.
Расчёт доли проблемных сессий и интерпретация аномалий по типам устройств.
Оценка лояльности аудитории на основе разных метрик поведения.

Инструменты и приёмы работы с SQL:
Формирование аналитических запросов с использованием SELECT, WHERE, GROUP BY, HAVING, JOIN.
Очистка и объединение данных из нескольких таблиц.
Применение подзапросов и CTE
Проведение когортного анализа
Экспорт и визуализация результатов в Excel для подготовки презентации.
